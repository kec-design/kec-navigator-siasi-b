# KEC Navigator 디자인 리뉴얼 시안

기존 서비스 https://kecnav.dosystem.kr/ 의 화면 구조에 전달받은 Figma 디자인의 파란색, 그라데이션, 둥근 카드 스타일을 적용했습니다.
디자인 참고: https://hue-iris-85834718.figma.site/

## 실행

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5175
```

미리보기: http://127.0.0.1:5175/

현재 컴퓨터에서는 KEC-work/node_modules를 참조합니다. 이 폴더만 다른 컴퓨터로 이동하는 경우 해당 심볼릭 링크를 제거한 다음 npm install로 의존성을 설치하세요.

## 구현 범위

- 상단 챗봇 / 원문뷰어 전환
- 챗봇과 근거 원문 분할, 드래그 및 방향키로 분할 너비 조정
- 일부 목차 탐색, 목차 검색 모달 및 Cmd/Ctrl+K 단축키
- 질문 입력과 시안용 응답 안내
- 라이트 / 다크 모드와 모바일 레이아웃
- 원문 표지 1쪽, 확대/축소, 폭 맞춤, 펼침 레이아웃

## 실제 서비스 연결이 필요한 항목

AI 답변, 전체 목차/검색, 인용 조항과 원문 페이지 매핑, 전체 페이지 탐색, 2020년 버전 데이터는 아직 연결되어 있지 않습니다. 질문에 대한 규정 답변을 생성하거나 임의의 규정 내용을 제공하지 않습니다.
현재 원문 이미지는 기존 사이트에서 확인한 공개 표지 1쪽 URL을 참조합니다. 네트워크가 없거나 해당 URL이 변경되면 표시되지 않습니다. 검색은 로컬에 포함된 16개 목차 항목만 대상으로 합니다.

## 수정할 파일

- src/App.tsx: 화면 구조, 상태, 상호작용
- src/renewal.css: 리뉴얼 스타일과 반응형 배치
- src/index.css: 기존 폰트 설정

원본 및 Claude 작업 폴더 KEC-work는 수정하지 않았습니다.

## 확인

npm run build 및 TypeScript 검사 통과. 브라우저에서 검색/결과 선택/원문 전환/질문 입력/확대/테마 전환, 데스크톱 및 390px 모바일 화면 확인.
